# Rust Port Implementation Plan

Historical migration record. The temporary reference implementation and paths
described here were subsequently removed by `2026-11-09-python-cleanup.md`.
Use the README and plugin guide for current setup and verification commands.

**Goal:** Replace Teem's Python runtime with a native Rust executable without losing existing task state or safety contracts.

**Architecture:** One binary; modules mirror the existing contract boundaries. Python remains a test oracle, not a runtime dependency. Work directly in this checkout, without worktrees or live service changes.

**Tech Stack:** Rust, SQLite, JSON/TOML, loopback HTTP, Git, Unix processes; existing TypeScript TUI.

## Operational boundary

No live service, OpenCode configuration or task database was changed. The old
Python service remains running. Root Python paths are temporary links into the
frozen reference so its configured entry point and check-helper paths do not
break before an approved cutover. The new manifest, binary, MCP and check helper
do not invoke Python. TypeScript remains the OpenCode TUI host adapter.

This record qualifies the source, not an installed service or release. Source
publication was separately authorised after verification. No new models were
called, and no unfinished task or uncertain native input was replayed. A live
Rust service cutover and paid end-to-end validation remain separate operations.
